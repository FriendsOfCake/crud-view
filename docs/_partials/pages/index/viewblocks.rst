Available Viewblocks
--------------------

.. include:: /_partials/pages/viewblocks-intro.rst

The following custom view blocks are available for use within index pages:

- ``before_index``: Rendered before the index page content.
- ``search``: Rendered below the action header and contains the search filter
  form. By default it is filled with the ``search`` element.
- ``after_index``: Rendered after the index page content.

.. note::

    The ``actions`` block, which is rendered by the ``action-header`` element,
    is available on all pages.
